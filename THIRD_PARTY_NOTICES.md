# Third-party components

Orbit uses React, Next.js, shadcn/ui, Radix, Tailwind CSS, Lucide, Mermaid and
DOMPurify. Their licenses remain applicable; package metadata contains each
dependency's license.

The bundled Inter variable font is licensed under the SIL Open Font License.
The complete license is included in public/fonts/OFL.txt.

The EffectButton and reduced motion hook originate from Zyeon UI. The public
registry is configured in components.json; no paid components or registry
credentials are included.
